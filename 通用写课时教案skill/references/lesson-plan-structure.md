# 教案结构详解

教案按字段格式输出。**字段有两个来源**：用户没提要求时用 SKILL.md 4.1 的**默认字段表**；用户上传模板或指定了字段时，按从模板/要求中提取、并经用户确认的清单输出。以下为每个字段的详细写法、格式要求与示例。**所有示例仅用于说明写法，不是教案要写的内容。**

> **两种输出形态**：无模板时按 `{字段:内容}` 文本框格式输出；用户提供 `.docx` 模板且环境可写 Word 时，改为在原模板中填充、保留全部样式（详见本文第 11 节）。字段的**写法与篇幅标准在两种形态下完全一致**，区别只在承载容器。

**写法标准**：各字段的写法与篇幅以参考范本 `references/example-lesson-plan.md` 为准——学习活动只写学生行为、学习任务一句话、学习评价 1-3 条，全篇精炼不铺陈。编写前先对照范本。

> **但有两处按用户在 Phase 1.5 的选择走，不硬套本节**：
> 1. **篇幅**——用户选「精炼」（或不答）时按本文标准；选「详实」时按 SKILL.md 4.3B 展开（活动写多轮预设与典型错误、评价 2-4 条附达成度、可补设计意图），此时范本只作写法逻辑的参照，篇幅上限放宽。
> 2. **学习活动是否写教师**——用户选「只写学生」（或不答）时，本节所有"不写教师行为"的要求全部有效；选「学生 + 教师都写」时，可写师生活动对照（导入、追问、板书、巡视、组织汇报），但仍以学生活动为主体。
>
> 文中凡出现"不得出现教师行为""每条一句话"这类表述，**默认按精炼 + 只写学生的档位理解**；用户选另一档时按上述规则覆盖。

---

## 1. 课题

以第几课时+本次教学内容命名，如：`第5课时 练习二十`、`第1课时 认识时间`、`第3课时 万以内的加法和减法（一）——连减求剩余`。

## 2. 课型

根据教学内容选择，课型名称依据学科特点确定，如：**新授课、练习课、复习课、活动课**等（数学学科常用：新授课、练习课、复习课、数学活动课；其他学科按学科惯例调整，如语文可有讲读课、作文课、口语交际课等）。

## 3. 学习目标

**核心要求：**

- 不出现旧课标三维目标的标题词（知识与技能、过程与方法、情感态度与价值观）
- 围绕"大概念"的落实进行目标设置，由**常规目标和核心目标**组成
- 各目标之间体现**知识、能力和素养的进阶**
- 目标从**学生本位**出发表述（"学生能……""经历……"）
- 各目标要体现"过程与方法"的**渗透**（写"借助……""经历……"等过程性表述）
- 切忌"空、大、泛、假"——每条目标都要具体、可达成、可评价

**写法参考（以数学学科为例，示例非教案内容）：**

1. 经历解决问题的一般过程，能根据数量关系列综合算式解决"连减求剩余"的实际问题，明确小括号在综合算式中的作用，培养应用意识。
2. 借助画图分析数量关系，建立几何直观。
3. 能解释计算结果的实际意义，提高表达能力，发展思维。

**写作要领：** 示例中第 1 条是知识目标（常规目标），第 2、3 条逐步递进到能力与素养（核心目标）。写目标时按"知识 → 方法/能力 → 素养"的进阶组织，动词用"经历、能、借助、明确、建立、发展、培养"等，不用"了解、掌握"这类空泛词（除非教材要求确实如此）。其他学科按本学科的核心素养（如语文的语言运用、思维能力等）替换。**篇幅：3 条左右，每条一句话，不展开论述。**

## 4. 学习重点难点

分为**重点、难点**两部分书写：

- **重点**：参考知识目标来写（即学生必须掌握的核心知识/技能）
- **难点**：依据学情来写，参考教师教学用书中对难点的阐述（通常是学生认知上容易出错或抽象难理解之处）

## 5. 教学准备

列出本节课需要的教具学具，如：学习单、课件、实物教具、学具等（按学科与内容准备，如数学的学具、语文的朗读音频、科学的实验器材）。

## 6. 学习方法

列出本节课学生采用的主要学习方法，如：自主探究、动手操作、合作交流、画图分析、对比辨析等（依据学科、课型与内容选定）。

## 7. 学习活动预设

根据学生学情，预设后面的学习主题中**可能出现的情况**：学生可能的回答、做法、易错点、困惑点（用"预设 1、预设 2……"列出）。**只写学生可能出现的情况，不写教师如何应对。**

学情推断依据：**学生学段（年级）**的认知水平与已有知识基础；若用户提供了学校、地区等信息，结合当地学生特点综合判断；未提供时不得虚构具体学校。

## 8. 环节字段（教学过程）

教学过程固定为**四个环节**，每个环节对应 4 个字段：`环节N`、`环节N学习任务`、`环节N学习活动`、`环节N学习评价`（N=一、二、三、四），四者缺一不可。

### 环节N（环节名称字段）
填该环节的主题名称，如：`复习导入`、`探究新知`、`巩固练习`、`课堂小结`。

### 环节N学习任务
写学生要完成的任务。**必须简洁：一句话写明任务内容与出处**（题目或页码），不写操作步骤——具体怎么做放在"学习活动"字段。参照范本，如：

> 【学习任务一】用数方格的方法数出平行四边形面积。观察表格中的数据，说说你发现了什么？
>
> 【学习任务二】基础练习：一块平行四边形的麦地底长 250 米，高是 78 米，它的面积是多少平方米？先独立解答。

若一个环节有多个任务，用"【学习任务一】【学习任务二】……"编号。

### 环节N学习活动

写**学生在课堂上具体怎么做**，按"活动一、活动二、活动三……"或编号（1.1、1.2……）组织。**只写学生行为**——独立思考、独立完成、小组合作、同桌交流、全班汇报、动手操作等，并可在活动条目下列出学生可能的回答与做法（"预设 1：……预设 2：……"）。**不得出现任何教师行为**（如"教师板书""教师巡视指导""教师引导""教师讲解""教师提问"等）。

> **用户选了「学生 + 教师都写」时**：可改为师生活动对照，允许写教师如何导入情境、如何追问、如何板书、如何巡视与个别指导、如何组织汇报与总结。但学生活动仍是主体，教师行为写成"服务学生活动"的动作，不写成教师独角戏。例：
>
> > 1. 观察主题图，交流看到的图形。（学生说，教师按学生回答贴出图形卡片）
> > 2. 小组合作剪拼，尝试把平行四边形变成长方形。（教师巡视，对卡住的小组提示"能不能沿高剪"）

参照范本，如：

> 活动一：观察与交流
> 1. 观察主题图，交流看到的图形，说说哪些图形的面积会计算。
> 2. 比较两个花坛的面积，说说自己的想法。
>
> 活动二：小组合作探究
> 1. 按要求合作学习，利用学具通过剪一剪、移一移、拼一拼探索图形面积，和组内成员分享并完成学习单。
> 2. 组内交流发现，班级汇报。
> 预设 1：先沿高剪开，把三角形向右平移，再拼成长方形。
> 预设 2：平行四边形的面积与底和高有关系，面积 = 底 × 高。
>
> 活动三：独立练习与汇报
> 1. 独立完成练习十九第 1、2 题。
> 2. 全班汇报解答过程，注意解题格式规范。

### 环节N学习评价
写做到什么程度、如何评价。**1-3 条可观察的达标标准**，从学生角度表述（"能……"）。**评价主体**：自评、互评、师评；**评价形式**：口头、批阅。如：

> 评价标准：
> 1. 能在方格纸中正确数出图形的面积，发现平行四边形的面积等于底乘高。
> 2. 能通过拼、剪等方法把平行四边形转化成长方形，推导出面积公式。
> 评价主体：互评、师评
> 评价形式：口头

## 9. 作业设计字段

对应 4 个输出字段，缺一不可：

1. **基础作业必做**：纸笔作业中的必做部分（面向全体学生的基础巩固题）
2. **基础作业选做**：纸笔作业中的选做部分（面向学有余力学生的提升题），体现分层作业
3. **个性化作业**：根据学生兴趣/能力差异设计的弹性作业
4. **实践作业**：**个体+小组**形式结合的动手实践类作业

## 10. 教学反思（可选追加字段）

输出格式默认不含此字段；**仅当用户明确要求时**，在末尾追加 `{教学反思:此处填写对应内容}`。包含三部分，缺一不可，按以下顺序写：

1. **教学问题重现**：设想/复盘本节课可能出现的教学问题（描述具体场景）
2. **原因分析**：分析该问题产生的原因（学情、教学设计、课堂组织等角度）
3. **教学重构**：给出改进后的教学调整方案（具体可操作）

## 11. Word 模板输出（通路 B）的字段映射与排版

用户提供了 `.docx` 教案模板、且环境可写入 Word 时，**不再输出花括号字段块作为交付物**，而是把上述各字段内容填入模板。以下为填充时的处理规则。

### 11.1 字段提取与映射

**提取 → 列清单 → 用户确认 → 再填充**，四步不可颠倒。下表是提取后做语义匹配时用的对照参考，**不是**可以跳过确认直接套用的固定表。

1. 先完整读一遍模板，列出它的所有字段名（含表格行标题、单元格提示语、下划线前的标签），记下排列顺序与合并关系。
2. 对照 SKILL.md 4.1 默认字段表，把模板字段分成三类：**可直接对应**、**语义相近可归并**、**模板独有（默认表没有）**。
3. 把这三类整理成清单 + 拟填/拟不填建议，请用户确认（话术见 SKILL.md 1.4）。用户确认后的清单即最终字段清单，后续一律照此执行。
4. 下表供匹配时参考：

| 模板常见写法 | 对应教案字段 |
|-------------|-------------|
| 课题 / 教学内容 / 授课内容 | 课题 |
| 课型 / 课程类型 | 课型 |
| 教学目标 / 学习目标 | 学习目标 |
| 教学重点 / 重点 | 重点 |
| 教学难点 / 难点 | 难点 |
| 教学准备 / 教具学具准备 | 教学准备 |
| 教法学法 / 学习方法 | 学习方法 |
| 学情分析 / 学生情况预设 / 预设 | 学习活动预设 |
| 教学过程 / 教学活动 / 教学环节 | 环节一～环节四（4 组字段合并写入） |
| 作业设计 / 作业布置 | 基础作业必做、基础作业选做、个性化作业、实践作业 |
| 板书设计 | 模板独有，默认字段表无此项 → 需在确认清单里问用户写不写 |
| 教学反思 / 课后反思 | 仅用户要求时填写 |
| 授课班级 / 授课日期 / 授课教师 | 模板独有 → 问用户是否需要代填 |

5. 合并写入"教学过程"区域时，内部结构保持：

```
环节一：复习导入
【学习任务】……
【学习活动】1.1 …… 1.2 ……
【学习评价】1. ……
```

6. 用户确认"要写"的模板独有字段，按模板要求写；确认"不写"的，保留模板原提示文字或留空，**不擅自填内容、不擅自删行**。

### 11.2 排版处理

1. **只填不改**：字体、字号、加粗、颜色、段落间距、行距、缩进、编号样式、表格边框与合并单元格、页边距、页眉页脚，一律保持模板原样。
2. **占位提示原位替换**：模板里的"（此处填写……）""：____"等提示，用正文内容替换掉，不留空行、不保留提示语。
3. **沿用模板的段落格式**：新写入的每一行都继承该单元格/该段落的既有格式，不要新建不同格式的段落。
4. **编号用模板的方式**：模板用"1. 2. 3."就继续用阿拉伯数字；模板用"①②③"或"（一）（二）"就沿用模板符号，不擅自混用。
5. **单元格空间不足时先精简**：按当前档位的篇幅标准压缩表述（精炼档：任务一句话、活动每条一句话、评价 1-3 条；详实档：压缩展开部分而非取消展开），**不要**为了塞下文字去改行距、缩字号、加高行高。
6. **另存新文件**，文件名含课题，不覆盖用户原模板；交付时给出"模板字段 ↔ 教案字段"对照表。

### 11.3 环境无法写 Word 时

回退到文本框格式，仍按模板字段的顺序与标题组织文本（把 `{课题:……}` 改为 `课题：……` 这类模板同款标签），并告知用户可直接整段粘贴进模板对应位置。

## 12. 两个可调档位（按 Phase 1.5 的用户选择执行）

本文其余各节描述的是**默认档位（精炼 + 只写学生行为）**。用户明确选择另一档时，按本节覆盖。

### 12.1 篇幅：精炼 / 详实

| 字段 | 精炼（默认） | 详实 |
|------|------------|------|
| 学习目标 | 3 条左右，每条一句话 | 3-5 条，可分点展开"借助……经历……形成……" |
| 学习任务 | 一句话写明任务与出处 | 一句话交代任务后，补一句要解决什么问题、达到什么程度 |
| 学习活动 | 编号分条，每条一句话；预设简写 | 可写多轮，展开不同层次学生的做法、典型错误、分歧点、操作步骤与材料；预设各写完整句子 |
| 学习评价 | 1-3 条"能……"式标准 | 2-4 条，可附达成度描述（如"☆ 基本达成 / ☆☆ 熟练 / ☆☆☆ 能迁移"） |
| 设计意图 | 不写 | 可在字段内补一句"为什么这样安排" |

**详实的底线**：仍不得注水——同一层意思不重复，不把一句话拆成三句说；所有展开都要落在"学生可能怎么想、怎么做、会错在哪"上。

### 12.2 学习活动：只写学生 / 师生活动都写

| 档位 | 可写内容 | 禁忌 |
|------|---------|------|
| 只写学生（默认） | 独立思考、独立完成、小组合作、同桌交流、全班汇报、动手操作；预设学生回答与做法 | 不得出现任何教师行为（板书、巡视指导、引导、讲解、提问、示范、总结） |
| 学生 + 教师 | 上述学生活动 + 教师导入情境、追问、板书、巡视与个别指导、组织汇报与总结 | 不得写成教师独白；教师行为须服务于学生活动；学习目标、评价、作业仍按学生本位表述 |

> 未确认过用户偏好时，一律按默认档位（精炼 + 只写学生行为），不得自行切换。

## 参考范本

各字段的写法与篇幅标准参照 `references/example-lesson-plan.md`（从真实单元教学设计《多边形的面积》提取）：

- **学习任务**：一句话写明任务内容与出处，不写操作步骤
- **学习活动**：只写学生行为（独立完成、小组合作、全班汇报、动手操作），预设学生可能的回答与做法；不出现教师行为
- **学习评价**：1-3 条"能……"式达标标准 + 评价主体（自评、互评、师评）+ 评价形式（口头、批阅）
- **整体篇幅**：目标 3 条左右、活动每条一句话、全篇精炼不铺陈

> 以上是**精炼档**的标杆。用户选详实时，可参照其写法逻辑但放宽篇幅，见第 12 节。
