# 教材库使用说明

本目录存放**教材解析版 Markdown**，是教案写作三级取用链路中**第二级（用户文字描述）的检索对象**：

```
①用户上传的资料  →  ②用户的文字描述（并用它检索本教材库）  →  ③联网搜索（必须最新版教材）
```

用户给了文字描述但没给教材原文时，用描述中的关键词（版本、年级册次、单元名、课题、页码、题目首句、知识点）到这里找可参考的原文，用来**核对、补全、校正**用户的描述；本库查不到，才降级到联网检索最新版教材。

> ⚠️ **重要：本库内容均为 OCR / 解析结果，只能当「搜索范本」，不是绝对正确的原文。**
> 数字（0/8、1/7、5/6 最易混）、单位（m、kg、°、cm²）、分数与小数格式、上下标、图示上的标注、表格行列错位，都可能识别错。引用时发现可疑，必须回原件核对或联网比对**最新版教材**修正，并在输出中标注「原件 OCR 疑误，已按 XX 修正」——**既不照错抄，也不悄悄改**。

## 一、目录怎么建

按 `学科 / 版本 / 年级册次` 三级组织，一本教材（或一册的教师用书）对应一个 `.md` 文件：

```
教材库/
├── README.md                      ← 本文件
├── 数学/
│   └── 人教版/
│       ├── 四年级上册/
│       │   ├── _索引.md           ← 本册目录索引（必建，写清单元/课时/页码）
│       │   ├── 教材_人教版数学四年级上册.md
│       │   └── 教参_人教版数学四年级上册.md
│       └── 三年级上册/
└── 语文/
    └── 部编版/
```

**新增一册的步骤**：建目录 → 放 `.md` 文件 → 写该册的 `_索引.md` → （可选）在本文件末尾的「全库清单」里补一行。

## 二、文件怎么命名

统一格式，便于检索时按名匹配：

| 类型 | 命名格式 | 示例 |
|------|---------|------|
| 教材正文 | `教材_{版本}{学科}{年级}{册}.md` | `教材_人教版数学四年级上册.md` |
| 教师用书 | `教参_{版本}{学科}{年级}{册}.md` | `教参_人教版数学四年级上册.md` |
| 课程标准 | `课标_{学科}{年份版}.md` | `课标_数学2022年版.md` |
| 补充内容 | `补学_{年级}{册}_{内容}.md` | `补学_三年级上册_认识时间.md` |
| 单元专题 | `单元_{版本}{学科}{年级}{册}_{单元名}.md` | `单元_人教版数学四年级上册_大数的认识.md` |

> 一册教材内容太大时，可拆成「按单元」的多个文件（用 `单元_` 前缀），并在 `_索引.md` 里列出每个单元对应的文件名。

## 三、每份文件怎么写（推荐结构）

在文件开头放一段元信息，便于 AI 一眼定位，正文再按教材顺序排：

```markdown
---
版本: 人教版（2024 新版）
学科: 数学
年级册次: 四年级上册
类型: 教材正文
页码基准: 纸质教材页码
---

# 人教版数学四年级上册

## 第一单元 大数的认识

### 第1课时 亿以内数的认识（P2-P4）

**教材原文**
（照抄教材上的情境图说明、例题、对话框、结论性语句）

**例题**
例1：……
例2：……

**做一做**
1. ……
2. ……

**练习一**
1. ……（P8）
2. ……
```

要点：

1. **照原文抄，不要改写**——教案里的题目必须来自教材原文，库里有原文就不联网。
2. **保留页码**：每课时、每题后面标 `（P数字）`，Agent 靠这个把"64-66页"映射到具体内容。
3. **例题、做一做、练习分开标标题**，方便按题型取用。
4. **教师用书单独成文件**，只记编写意图、教学建议、易错点，不要混进教材原文。
5. 图片类内容（主题图、几何图）用文字描述清楚，如"主题图：操场上有 4 排学生，每排 12 人"。

## 四、`_索引.md` 怎么写

每册一个，是检索的入口。推荐格式：

```markdown
# 人教版数学四年级上册 索引

- 教材正文：`教材_人教版数学四年级上册.md`
- 教师用书：`教参_人教版数学四年级上册.md`

| 单元 | 课时 | 页码 | 所在文件 | 章节标题 |
|------|------|------|---------|---------|
| 第一单元 大数的认识 | 第1课时 亿以内数的认识 | P2-P4 | 教材_人教版数学四年级上册.md | ## 第1课时 亿以内数的认识 |
| 第一单元 大数的认识 | 第2课时 亿以内数的写法 | P5-P6 | 教材_人教版数学四年级上册.md | ## 第2课时 亿以内数的写法 |
| 第二单元 公顷和平方千米 | 第1课时 公顷的认识 | P34-P35 | 教材_人教版数学四年级上册.md | ## 第1课时 公顷的认识 |
```

## 五、检索时 Agent 该怎么做

**前提**：走到这一步，说明已经确认「用户没有上传含本次内容的资料」，手上是**用户的文字描述**。检索目标是给这份描述找到原文依据。

1. 从用户描述里提取关键词：**教材版本、年级册次、单元名、课题名、页码、题目首句、核心知识点**；
2. 按关键词定位：全库清单 → `学科/版本/册次` 目录 → 读该册 `_索引.md`，用表里的页码/课时/单元名找到具体章节；
3. 打开对应 `.md`，按章节标题取内容，**用原文核对用户描述**（题目表述、数据、页码、所属单元课时），教案一律用库中原文；
4. **核对时留意识别错误**：库中文本是 OCR 结果，重点查数字、单位、分数、上下标、图示标注、表格行列。可疑处 → 回用户上传的原件、或联网比对最新版教材修正，并在输出中注明「原件 OCR 疑误，已按 XX 修正」；两方对不上又判断不出，问用户；
5. **查到矛盾点时问用户**：如描述说的页码与索引不符、版本与库中版本不一致，先问用户以哪个为准，不自行取舍；
6. **库中没有这本册次或这个版本** → 带着描述降级到联网检索**最新版教材**，输出中注明资料来源为网络，并提示用户可把结果整理成 Markdown 补入本库，下次直接复用；
7. 联网也找不到 → 如实告知缺什么，按描述撰写并列出待核对项。

## 六、页码锚点约定（已入库文件遵循）

教材类文件在**每页起始处**插入一行锚点注释：

```markdown
<!-- ==== P64 ==== -->
```

- 页码用**纸质教材页码**（P1 起算），不是 PDF 页序；
- 查「第 64-66 页」→ 搜 `==== P64`，内容范围到下一个 `==== P` 锚点为止；
- 前置页（封面、目录、扉页）用 `PDF3` 这类标记，避免与正文页码混淆；
- 教参若原件页数过多被分段解析，分段处用 `## 【第 201 页起（第二段）】` 标注，检索时按「单元名 + 小节名」定位而不是页码。

生成锚点的做法：用 `mineru-open-api extract -f json` 拿到 `page_idx`，与 `-f md` 的文本做锚定后插入；单次解析上限 200 页，超过要 `--pages` 分段。
